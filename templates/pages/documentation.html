Inscription & Connexion

Pages d'authentification

GET/auth/register/ — Formulaire d'inscription (3 étapes)
POST/auth/login/ — Connexion par email + mot de passe
GET/auth/logout/ — Déconnexion
GET/auth/forgot-password/ — Réinitialisation de mot de passe
GET/auth/google/ — Connexion Google OAuth2

Processus d'inscription

  • 1
    Identité : prénom, nom, email, nationalité, date de naissance (min. 16 ans), métier souhaité
  • 2
    Sécurité : mot de passe (min. 10 car., maj + min + chiffre + symbole) avec indicateur de force
  • 3
    Consentements : acceptation CGU/politique de confidentialité (obligatoire), newsletter (optionnel)
Sécurité : après 5 tentatives de connexion échouées, l'adresse IP est bloquée pendant 1 heure (django-axes). La réinitialisation passe par email.

Tests & Certifications

Système de certification

  • Score de réussite : 70 % minimum
  • Certificat généré automatiquement après le test global
  • Chaque certificat porte un hash SHA-256 unique vérifiable publiquement
  • Vérification en ligne : /verification-certificat/
  • Téléchargement PDF disponible depuis le dashboard
Les parcours Contrôleur Aérien et Technicien Aéronautique sont accessibles gratuitement sans abonnement.

Assistant IA

Chatbot spécialisé aéronautique

L'assistant IA (powered by OpenAI) est disponible uniquement dans le contexte d'un cours actif.

  • Endpoint API : POST /api/chatbot/
  • Accès refusé (403) si l'utilisateur n'est pas dans un cours
  • Questions limitées au contenu pédagogique du parcours en cours
  • Historique conservé dans la session navigateur

Mode hors-ligne (PWA)

Progressive Web App

  • Manifest : /static/manifest.json
  • Service Worker : /sw.js
  • Page hors-ligne : /offline/
  • Icônes : 72px → 512px (tous formats)
  • Installable sur Android, iOS et desktop Chrome/Edge

Pour installer l'app : cliquer sur l'icône d'installation dans la barre d'adresse du navigateur (Chrome/Edge) ou « Ajouter à l'écran d'accueil » sur mobile.

Commandes de gestion

# Initialiser les données de test (utilisateurs + parcours) python3 manage.py init_test_data # Appliquer les migrations python3 manage.py migrate # Collecter les fichiers statiques python3 manage.py collectstatic --noinput # Créer un super-utilisateur manuellement python3 manage.py createsuperuser # Lancer en développement bash start.sh # Lancer directement avec Gunicorn (production) gunicorn --bind=0.0.0.0:5000 --reuse-port wsgi:application

Script start.sh (ordre d'exécution)

  • 1
    python3 manage.py migrate — applique les migrations de BDD
  • 2
    python3 manage.py init_test_data — seed utilisateurs et parcours (idempotent)
  • 3
    python3 manage.py collectstatic — copie les fichiers statiques
  • 4
    gunicorn ou runserver — démarrage du serveur

Déploiement

Déploiement sur Replit (Autoscale)

  • Cible : deploymentTarget = "autoscale"
  • Serveur : Gunicorn --bind=0.0.0.0:5000 --reuse-port wsgi:application
  • BDD production : PostgreSQL (configurer DATABASE_URL)
  • Fichiers statiques : collectstatic au démarrage via start.sh
Avant chaque déploiement : vérifier que DJANGO_DEBUG=False, que tous les secrets sont dans Replit Secrets (pas dans .env), et que python3 manage.py check --deploy ne retourne pas d'erreur critique.
